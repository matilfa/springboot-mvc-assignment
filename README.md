This is a school assignment on Spring Boot and Spring MVC. 

## How to run
- Git clone the repository to your local machine.
- Open a UNIX terminal in the project root.
- Run the `run.sh` script by executing the following command: `bash ./run.sh`
- Wait for the server to start, then you can test the application.

## Endpoints
You can navigate the application using the GUI or by pasting the URLs in your browser.
When searching for a genre that does not exist, you will see an error message on the web page.

- http://localhost:8080/home	
- http://localhost:8080/books 
- http://localhost:8080/genre
- http://localhost:8080/genre?type=Fantasy 
- http://localhost:8080/genre?type=Deckare
